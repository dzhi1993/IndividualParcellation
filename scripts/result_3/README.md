# Figure Result 3

This folder contains scripts used for the third paper result/figure block, centered on task coverage maps.

## Scripts

- `make_task_coverage_map.py`: generates task coverage maps used in the manuscript results.

## Expected inputs

- Atlas definitions and model resources configured through `global_config.py`.
- Task data and evaluation assets available through the dependent fusion/parcellation projects.

## Outputs

- Coverage maps and related derived outputs used for the corresponding figure panel.

## Release note

This script should be treated as figure-generation code for the paper. It is useful for reproducibility, but it is not yet a release-safe user-facing command.
