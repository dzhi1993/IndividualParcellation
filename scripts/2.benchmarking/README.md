# Result 2: Benchmarking mRBM-HBP Against Resting-State Parcellation Methods in HCP

This folder contains the scripts for the HCP resting-state benchmark in Result 2. The goal of this result section is to compare the individual parcellations estimated by our mRBM-HBP pipeline against an existing resting-state parcellation method, MSHBM, using the same HCP test subjects and the same evaluation metrics.

## Workflow

1. Estimate or collect individual parcellations for the HCP test subjects.
   - MSHBM/Kong-style individual maps are loaded from the precomputed MSHBM output directory.
   - mRBM-HBP individual maps are loaded from the HBP `.dlabel.nii` output.

2. Train and apply the mRBM-HBP resting-state model on the matching HCP data.
   - `../../train_group.py` fits the HCP resting-state group model used by the mRBM-HBP pipeline.

3. Compare MSHBM and mRBM-HBP individual maps.
   - `evaluation_indiv.py` evaluates both model families through the same loop and output schema.
   - Task evaluation computes DCBC on all contrasts and task inhomogeneity by task domain.
   - Rest evaluation computes resting-state homogeneity.

## Scripts

- `../../train_group.py`: trains the HCP resting-state group model used by the mRBM-HBP benchmark through `training_type='rest'`.
- `evaluation_indiv.py`: merged benchmarking entry point for MSHBM and mRBM-HBP individual parcellations.
- `evaluation_MSHBM_indiv.py`: legacy single-model script for the MSHBM baseline, kept for reference.
- `evaluation_HBP_indiv.py`: legacy single-model script for the mRBM-HBP output, kept for reference.

## Expected Inputs

- HCP imaging data under the configured `ERIS_DIR`, usually `Tian/HCP_img`.
- HCP subject-list files under `../../replication/subject_list`.
- MSHBM/Kong2019 group-prior metadata under `../../replication/MSHBM_17networks`.
- Precomputed MSHBM individual parcellations for the HCP test subjects.
- mRBM-HBP model outputs under the configured model directory.
- Dependencies from `Functional_Fusion`, `FusionModel`, and `HierarchBayesParcel`.

## Outputs

The scripts write model and evaluation outputs to the configured lab model/evaluation folders. Typical outputs include:

- fitted mRBM-HBP group model `.tsv` / `.pickle` files
- individual parcellation `.dlabel.nii` or probability outputs generated by downstream HBP workflows
- evaluation `.tsv` files comparing MSHBM and mRBM-HBP performance

## Notes

These are paper-reproduction scripts. They assume access to the lab filesystem and the HCP-derived intermediate files used for the manuscript. The intended use is to reproduce the Result 2 benchmark, not to provide a general command-line interface.
