# Result 3: Group Task/Rest Comparison

This folder contains scripts and notebooks for the group-level task/rest comparison analyses. The main focus is comparing group parcellations trained from resting-state data, task data, and fused task/rest data.

## Files

- `make_task_coverage_map.py`: generates task coverage maps used in the manuscript results.
- `network_dice_similarity.ipynb`: plots network-wise Dice similarity matrices from precomputed group-parcellation correspondence tables.

Group parcellations are trained with the root-level `../../train_group.py` workflow. The notebook in this folder visualizes the resulting correspondence tables rather than retraining models.

## Network Dice Tables

`network_dice_similarity.ipynb` reads the following files from `../../results/3.task_rest_fusion`:

- `Table_S3_network_correspondence_HBP17REST_vs_MSHBM17.csv`: Table S3, Figure panel 2c.
- `Table_S6_network_correspondence_HBP17REST_vs_YEO17.csv`: Table S6, Supplementary Figure panel 3c.
- `Table_S7_network_correspondence_HBP17REST_vs_HBP17TASK.csv`: Table S7, main Figure panel 3c.
- `Table_S8_network_correspondence_HBP17FUSION_vs_HBP17REST.csv`: Table S8, main Figure panel 4b.
- `Table_S9_network_correspondence_HBP17FUSION_vs_HBP17TASK.csv`: Table S9, main Figure panel 4c.

Each table stores network-wise Dice values with permutation-test p-values in the same cell. The notebook extracts the Dice coefficient, removes empty table padding, and plots one 17-by-17 heatmap per parcellation pair.

## Expected inputs

- Atlas definitions and model resources configured through `global_config.py`.
- Subject-list files under `../../replication/subject_list` where required.
- Task data and evaluation assets available through the dependent fusion/parcellation projects.
- Precomputed network correspondence tables under `../../results/3.task_rest_fusion`.

## Outputs

- Task coverage maps generated by `make_task_coverage_map.py`.
- Network-wise Dice similarity heatmaps generated interactively by `network_dice_similarity.ipynb`.
